Rules

  • Paper only. No keys, no wallets, no signing, no orders, no claims. This page only reads public data.
  • Fee = shares × feeRate × price × (1 − price). Crypto 0.07, Sports 0.05, Finance/Politics 0.04, Geopolitics 0 (Polymarket fee docs).
  • An edge is only flagged at ≥ 300 bps after fees, and it is re-checked after slippage (10 shares, +50 bps per leg).
  • Baskets only count when every outcome has a price. Incomplete ones are skipped.
  • Prices refresh every 10 s directly from Polymarket, with a 6 s timeout. If that host does not answer, the page reads data/live.json (a public mirror built by GitHub Actions about every 5 min) and polls it every 60 s, retrying the direct host every 5 min. The market list refreshes every 5 min on a direct connection. Refreshing pauses when this tab is hidden and backs off after errors.
  • Kill switch: when the desk's STOP file is set, this page shows PAUSED and stops fetching.
  • Expect almost no tradable edges. This is a watcher, not a money-maker.
